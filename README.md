# Kent & Boenninghausen - Modern Web & Mobile Repertory

This repository contains the modernized digital repertory suite for Kent and Boenninghausen repertories, replacing legacy desktop implementations with modern cloud-enabled cross-platform applications.

## Projects in this Repository

- **[`web-app/`](./web-app)**: Next.js 15 web application for clinical homeopathic repertorization, symptom analysis, and patient management.
- **Mobile Version**: Planned cross-platform mobile application utilizing the unified repertory data and Supabase cloud synchronization.

## Quick Start (Web App)

```bash
cd web-app
npm install
npm run dev
```

For more details, see the [`web-app/README.md`](./web-app/README.md).
